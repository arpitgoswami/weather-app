# Weather App

## Overview
A lightweight, responsive weather application built with **HTML** and **Tailwind CSS**. Users can enter any location—city, country, or coordinates—and instantly view real‑time weather conditions, a short‑term forecast, and detailed metadata.

## Features
- **Flexible Location Input** – Free‑text field accepts city names, countries, or latitude/longitude pairs.  
- **Live Weather Data** – Retrieves up‑to‑date temperature, humidity, wind speed, and weather description via a public weather API.  
- **Responsive Design** – Clean, mobile‑friendly layout that adapts seamlessly across desktops, tablets, and smartphones.  
- **Current Conditions Card** – Displays temperature, feels‑like temperature, humidity, wind, and a brief textual summary.  
- **Short‑Term Forecast** – Shows a three‑day outlook with daily highs/lows and condition icons.  
- **Error Handling** – Handles network failures, invalid locations, and API rate limits gracefully with informative messages.  
- **Modern UI** – Utilizes Tailwind CSS for a polished, accessible interface with a custom color scheme and typography.

## Technology Stack
- **HTML5** – Semantic markup and page structure.  
- **Tailwind CSS** – Utility‑first styling for rapid, consistent design.  
- **Vanilla JavaScript** – API requests, data parsing, and DOM interactions.
