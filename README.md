# Weather App

A simple weather dashboard built with HTML, CSS, and React (via CDN).

## Features
- Search weather by city
- View current conditions
- See hourly and daily forecast details

## Run
1. Open `/home/runner/work/weather-app/weather-app/index.html` in a browser.
2. Enter a city name in the search box.

## Data Source
- Open-Meteo APIs for weather, geocoding, and air quality data.
